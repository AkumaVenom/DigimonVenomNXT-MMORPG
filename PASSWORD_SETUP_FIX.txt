DIGIMON VENOM NXT 0.3.0 - COMPLETE SETUP GUIDE

START WITH 01_SETUP_SERVER.bat IN THE NEW SERVER FOLDER.
The new native wizard handles XAMPP, the game database login, hosting and checks
in one window. No existing game database account or tamer account is required.

1. BUILD
   Extract the complete source ZIP into a NEW writable folder. Open the inner
   DigimonVenomNXT folder containing BUILD_ALL.bat. Do not run from inside the ZIP.
   Install Python 3.11 or newer for Windows x64, with the Python launcher,
   Add Python to PATH and Tcl/Tk support. Run BUILD_ALL.bat. It downloads the
   dependencies, verifies every included runtime asset and builds the programs.

2. USE THE NEW SERVER FOLDER
   Extract dist\Windows_Server_x64.zip to a permanent private folder outside
   dist. Rebuilding replaces dist, so keep your configured server elsewhere.
   Extract dist\Windows_Client_x64.zip into a separate client folder.

   UPGRADING ONLY: Stop the old world server. Back up its database and complete
   private config folder. Copy that config folder into the new server folder.
   Keep its database name and certificate authority to preserve progress/trust.
   FRESH INSTALL: There is no old config folder to copy.

3. OPEN THE WIZARD AND TEST XAMPP
   Start MySQL in XAMPP. Run 01_SETUP_SERVER.bat in the new server folder.
   Check that the setup version is 0.3.0.
   Local database defaults: host 127.0.0.1, port 3306, administrator root.
   Enter the password that already works with XAMPP. Blank is allowed if that
   administrator has no password. Run the connection check first.

4. CREATE THE GAME DATABASE LOGIN
   Fresh database default: digimon_venom_nxt. Keep the saved name on an upgrade.
   Let setup generate the game password, or choose one yourself. You do NOT
   need an existing game password or existing player account. Setup creates and
   checks the game login. Occupied usernames can be handled automatically while
   keeping the same database. No existing root or other MMO password is reset.
   For MySQL and game server on the same PC, the allowed account host is localhost.

5. LOCAL, LAN OR ONLINE HOSTING
   LOCAL ON THIS PC: Select local hosting. Use localhost for the connection.
   This uses the normal MySQL database and TLS. No router forwarding is needed.

   LAN: Use the server's LAN address/hostname in the hosting configuration.
   ONLINE: Use your public DNS hostname or public IP. Do not include https://,
   a path or :port in the hostname field. Choose the game TCP port; default 8765.
   Choose another unused game port if another MMO already uses 8765.

   The database port (usually 3306) and the game port (usually 8765) are separate.
   Internet play requires Windows Firewall permission and router forwarding of
   the GAME TCP port to the server PC. DNS must point to your reachable address.
   Setup cannot change your router, DNS or ISP settings for you.

6. APPLY THE CLIENT KIT
   Hosting creates Public_Player_Connection_Kit.zip containing only:
     config/client.json
     config/server-ca.pem
   Extract that kit INSIDE the client folder, merging config.
   Players do not manually install/trust a certificate in Windows.
   Only share the configured client and public kit. Keep the server folder,
   database credentials and certificate private keys private.

7. CHECK AND START
   Complete the wizard's readiness checks. Read any failed check before retrying.
   Local checks do not prove that Internet router forwarding works; test online
   hosting from another Internet connection too.
   Run START_WORLD_SERVER_CONSOLE.bat and wait for initial rival startup.
   Open PLAY_DIGIMON_VENOM_NXT.bat in the configured client folder.
   Use Register to create your player/tamer account. This is separate from MySQL.

IF A STEP FAILS
   The wizard keeps the exact error and stage visible. It also writes the
   sanitized report logs\setup-latest.json. Copy its diagnostic text or send that
   file for help. Password values are omitted; do not send config/server.json.

   1043: MySQL/MariaDB rejected the connection handshake. Check that the host and
   port are really the database service. It does not by itself mean bad password.
   1045: Authentication rejected. Check the username/password/account host for
   the stage reported. A remembered code cannot establish the actual cause.
   2003/refused: Start MySQL and check its configured host, port and firewall.
   Password policy: Choose an accepted GAME password or use automatic generation.
   Game port occupied: Choose a different unused game TCP port and update the kit.

REOPENING A STAGE / CONSOLE COMPATIBILITY
   01_SETUP_SERVER.bat              Complete native wizard
   02_SETUP_MYSQL.bat               Database stage of the same wizard
   03_SETUP_PUBLIC_HOSTING.bat      Hosting stage of the same wizard
   02_SETUP_MYSQL.bat --console     Advanced masked console database workflow
   03_SETUP_PUBLIC_HOSTING.bat --console   Advanced console hosting workflow
   Existing --answers and --console-passwords options remain supported on 02.
   An old setup_fix directory does not override the new full-release setup.

OPTIONAL SOURCE DEVELOPMENT WITHOUT XAMPP
   START_LOCAL_DEV.bat then PLAY_LOCAL_DEV.bat use a separate SQLite development
   save and loopback connection. This is separate from the normal MySQL/TLS setup.

BACKUP AND RENEWAL
   Back up the game database and entire private config folder regularly.
   Reopen hosting setup before the 397-day server certificate expires, retaining
   the CA. Restart the server after renewal. A changed hostname/port needs a new
   client kit. Keep the full CA backup so existing clients retain their trust.
